# Oakland High Schools Fan Art Project

Original fan art tribute designs celebrating Oakland Athletic League high schools and their communities.

## Project Overview

This project creates **original, stylized fan art** for Oakland's high schools, designed to appeal to alumni, parents, and fans. These are not official school materials—they're creative interpretations inspired by school mascots and colors.
