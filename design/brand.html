02

Logo & mark

The mark is a 16-point heraldic seal holding a checkmark — a certificate stamp for the digital age. Sixteen points is not decorative: it stands for the 16-control framework. The seal can stand alone; the wordmark is set in the display serif.

Clearspace

Keep clear space equal to the height of the seal's checkmark on all sides. Never crowd the mark with text or edges.

Minimum size

Mark: 24px / 0.25in. Full lockup: 120px / 1in wide. Below that, use the mark alone.

File formats

SVG for digital (the mark is vector). PNG @1x/2x/3x for avatars. One-color versions for fax/embossing.

✕ Don't recolor the seal

✕ Don't place on low contrast
03

Color palette

Deep institutional ground, one heraldic brass accent, and a strictly separate PASS/PARTIAL/FAIL semantic scale. Tap any swatch to copy its hex. Neutrals are hue-biased toward the accent — chosen, never default grey.

60% Neutral ground
26% Ink
10% Brass
4%

Ratio guide — brass is an accent of proof, never a background. Semantic colors signal status only; they are never used decoratively, and brass is never used to signal status.

07

Visual language

The seal motif

The brass seal is our proof-stamp. Use it sparingly, as punctuation — a certification moment, never wallpaper. An embossed macro of the seal is the signature texture.

Iconography

Line icons, 1.7px stroke, rounded joins, minimal. Shield, checkmark, gauge, document, lock — the vocabulary of protection and proof.

The Grandeza Score

The 270° gauge is a brand asset in its own right. Mono numerals, semantic band color, one cinematic sweep. It is the product, visualized.

Photography

Cinematic, low-key, teal-charcoal + brass grade. Real tradespeople with dignity — never cheesy stock. The human behind the compliance.

Patterns & texture

A faint blueprint/audit grid; the embossed seal. Both whisper "documentation" without shouting. Always low-contrast, behind content.

Layout

Generous whitespace = confidence. Control-code eyebrows (CTRL-01). Dossier-like sectioning. Data reads like evidence.
