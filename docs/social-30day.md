- Each link carries **UTM tags** so you can see, in GA4 → Reports → Traffic acquisition (or filter by `utm_content`), which day/platform converts:
  - `utm_source` = `linkedin` or `facebook`
  - `utm_medium` = `social`
  - `utm_campaign` = `30day`
  - `utm_content` = `dayNN`
- The raw tracked URL is a little long. If you prefer a clean look, run it through a shortener (Bitly/Dub) — the UTMs still register in GA4.
- **Paid ads are different:** send *paid* traffic to `grandeza.io/landing` (the long-form sales page). This 30-day plan is **organic**, so it uses `/scan`.

## DAY 26 — MATH — Control 03: TCPA Outbound Compliance (weight 9)

**Hook**
One text to a thousand customers with bad consent isn't a fine. It's a class action with no ceiling.

**Script / voiceover (30–45 sec if filmed)**
